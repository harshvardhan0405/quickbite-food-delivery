# 🍔 Quick Bites – Food Delivery Web App

Quick Bites is a modern, fully responsive **food delivery frontend website** built using HTML, CSS, and JavaScript.  
It simulates a real-world online food ordering experience with interactive menus, offers, and a dynamic shopping cart system.

---

## ✨ Features

- 🍔 Interactive food menu (Burger, Fries, Wraps, Soups, etc.)
- 🛒 Dynamic cart system
  - Add to cart
  - Increase / decrease quantity
  - Remove items
- 💰 Real-time total price calculation
- 🎁 Special value meal offers section
- 🎥 Hero section with video background
- 📱 Fully responsive design (Mobile, Tablet, Desktop)
- 💾 Cart data stored using `localStorage`
- 📩 Contact form UI
- ⚡ Smooth UI interactions and hover effects

---

## 🛠️ Tech Stack

- **HTML5** – Structure
- **CSS3** – Styling, Flexbox, Responsive Design
- **JavaScript (Vanilla)** – DOM manipulation & cart logic
